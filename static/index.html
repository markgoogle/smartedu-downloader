国家中小学智慧教育平台 · 教材下载台 免登录 · 原生PDF优先，自动回退图片合成（实测流程复现）

用 contentId 直达

粘贴平台教材的 contentId（UUID），直接读取公开详情 JSON。


  







  







  

    
工作流程（与 REPORT.md 实测一致）

    
    
      
  1. 详情 JSON：s-file-{1,2,3}.ykt.cbern.com.cn/zxx/ndrv2/resources/tch_material/details/{contentId}.json —— 公开、免登录、免 Token、免 Referer。
    2. 
      
  2. 路径 A（原生 PDF）：ti_items[source].ti_storages 的私有域直链去掉 -private → 公开桶。命中即得带文字层的出版社原生 PDF；约 1/3 命中，其余 403 AccessDenied。
    3. 
      
  3. 路径 B（图片合成）：preview URL 替换页码 /{page}.jpg，页数取 requirements.pagesize（≠ preview 条目数），并发下载后原样嵌入 PDF（无文字层，100% 可用）。
    4. 
      
  4. 校验：字节数 == ti_size、魔数 %PDF-、尾部 %%EOF、页数 == pagesize、pagesize+1 页应 403。
    5. 
    

    
注意

    
    
      
  • 全站请求不发送 Referer（实测带非白名单 Referer 会 403）。
    • 
      
  • 列表数据来自本地快照 catalog_data/*.json；平台目录端点需浏览器会话，可用 refresh_catalog.py 刷新。
    • 
      
  • 产物保存在 downloads/<contentId>/。
